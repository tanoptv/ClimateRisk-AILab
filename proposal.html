1 Project Overview — ภาพรวมโปรเจกต์
Project Title
ClimateRisk LINE Bot — ระบบ AI แจ้งเตือนความเสี่ยงภัยธรรมชาติสำหรับUser
Project Description
LINE Bot ที่ดึงข้อมูลภัยธรรมชาติ 6 ประเภทจาก 4 Free Public APIs ทุกชั่วโมง ให้ Claude Haiku 4.5 AI วิเคราะห์และให้คะแนนความเสี่ยง 1–5 พร้อมคำอธิบายภาษาไทย แล้วส่งรายงานสรุปเข้า LINE ทุกเช้า 07:00 น. และแจ้งเตือนฉุกเฉินทันทีเมื่อเกิดเหตุวิกฤต — เพื่อให้Userรู้ความเสี่ยงในจังหวัดตัวเองโดยไม่ต้องหาข้อมูลเอง
Business Context
Userในประเทศไทย ที่อาศัยหรือทำงานในพื้นที่เสี่ยงภัยธรรมชาติ และต้องการรับรู้สถานการณ์ความเสี่ยงในจังหวัดตัวเองแบบ Proactive โดยไม่ต้องเสียเวลาเปิดหลายเว็บไซต์และตีความข้อมูลดิบด้วยตัวเอง
2 Problem Statement — ปัญหาที่ต้องการแก้ไข
Current Problem
การติดตามความเสี่ยงภัยธรรมชาติในปัจจุบันต้องเปิดหลายเว็บไซต์แยกกัน ได้แก่ กรมอุตุนิยมวิทยา, AirVisual, กรมอุทกศาสตร์ และ NASA FIRMS และต้องตีความข้อมูลดิบเองว่า "อันตรายแค่ไหน" — ไม่มีระบบรวมข้อมูล ไม่มีการให้คะแนนความเสี่ยง และไม่มีการแจ้งเตือนเชิงรุก
Impact of Problem
เสียเวลา 15–20 นาที/วัน ในการค้นหาข้อมูลจากหลายแหล่ง · ข้อมูลกระจัดกระจาย ไม่มีจุดรวม · Userไม่รู้ว่าควรเตรียมตัวหรือระวังอะไร · อาจเกิดความล่าช้าในการรับรู้สถานการณ์วิกฤต ซึ่งส่งผลต่อความปลอดภัยในชีวิตและทรัพย์สิน
Proposed Solution
LINE Bot อัตโนมัติที่รวมข้อมูลภัยธรรมชาติ 6 ประเภทจาก 4 Free APIs ทุกชั่วโมง → ใช้ Hybrid AI Scoring (code threshold + Claude Haiku อธิบาย) ให้คะแนนความเสี่ยง 1–5 → ส่ง Daily Summary 07:00 น. และ Emergency Alert ทันทีเมื่อ score = 5 ผ่าน LINE Flex Message เข้า LINE ที่Userใช้อยู่แล้ว
3 Objectives — วัตถุประสงค์ (SMART Goals)
1
ดึงข้อมูลอัตโนมัติ 24/7: ดึงข้อมูลภัยธรรมชาติ 6 ประเภทจาก 4 Free APIs ครบ 77 จังหวัดทั่วประเทศไทย ทุก 1 ชั่วโมง อย่างต่อเนื่อง โดยมี Uptime > 95% ต่อรอบ
2
Risk Scoring แม่นยำ 100%: คำนวณ Risk Score 1–5 ด้วย threshold logic ที่กำหนดไว้ชัดเจน และให้ Claude Haiku AI อธิบายบริบทในภาษาไทยเมื่อ score ≥ 2 เพื่อให้เข้าใจง่ายโดยไม่ต้องตีความเอง
3
Daily Summary ตรงเวลาทุกเช้า: ส่งรายงานสรุปภัยธรรมชาติทุกเช้า 07:00 น. (GMT+7) ผ่าน LINE Flex Message ครอบคลุมทุกจังหวัดที่ผู้ใช้ลงทะเบียนติดตาม
4
Emergency Alert ภายใน < 5 นาที: แจ้งเตือนฉุกเฉินทันทีเมื่อ Risk Score = 5 (ระดับวิกฤต) โดยไม่รอรายงานรายวัน เพื่อให้ผู้ใช้รับรู้และเตรียมตัวได้ทันเวลา
5
ลดเวลาหาข้อมูลจาก 15+ นาที → 0 นาที: ผู้ใช้ไม่ต้องค้นหาข้อมูลเองอีกต่อไป ระบบส่งสรุปความเสี่ยงพร้อมคะแนนและคำอธิบายมาให้ใน LINE โดยอัตโนมัติทุกวัน

📥 Input
ข้อมูลดิบจาก 4 APIs: สภาพอากาศ, ฝุ่น PM2.5, แผ่นดินไหว, จุดไฟป่า — แยกรายจังหวัดทั่วไทย

Code คำนวณ Risk Score 1–5 ด้วย threshold → Claude Haiku อธิบายบริบทเฉพาะ score ≥ 2

👤 Human Review

Hallucination / Risk Mitigation: ใช้ Hybrid Scoring — Code-based threshold กำหนด Risk Score ก่อนเสมอ Claude Haiku ถูกเรียกเฉพาะเพื่อ "อธิบายเหตุผล" เท่านั้น ไม่ได้ใช้ AI ตัดสินคะแนน → ลด Hallucination Risk และรับประกัน Consistency 100%
6 Workflow / Architecture — ขั้นตอนการทำงาน (Input → Process → Output)
Step 1 — Scheduler
APScheduler Trigger
ทำงานทุก 1 ชั่วโมง (hourly check) และ 07:00 น. ทุกวัน (daily summary) โดยอัตโนมัติ 24/7 ตลอดเวลา
Step 2 — Fetch
API Data Fetchers
ดึงข้อมูลจาก Open-Meteo, OpenAQ, USGS, NASA FIRMS สำหรับทุกจังหวัดที่มีผู้ใช้ติดตาม
Step 3 — Score
Risk Scorer (Threshold)
risk_scorer.py คำนวณ Risk Score 1–5 แยกตาม 6 hazard types และบันทึกผลลง SQLite
Step 4 — AI
Claude Haiku Analysis
analyzer.py เรียก Claude Haiku เฉพาะเมื่อ score ≥ 2 สร้างคำอธิบายบริบทและคำแนะนำภาษาไทย
Step 5 — Check
Emergency Detection
ตรวจสอบ score = 5 (วิกฤต) → Trigger Emergency Alert ทันที โดยไม่รอ Daily Summary 07:00 น.
Step 6 — Notify
LINE Bot Delivery
line_bot.py ส่ง LINE Flex Message รายงาน/แจ้งเตือนเข้า LINE ของผู้ใช้ที่ลงทะเบียนทุกคน
Architecture Notes: Layer-based — fetchers/ · scorer/ · llm/ · bot/ · db/ · dashboard/ · Hybrid scoring รับประกัน Consistency + ให้ Readability · ngrok tunnel สำหรับ LINE Webhook บน Local Machine
